# Security policy

Please report security vulnerabilities **privately**, through
[Report a vulnerability](https://github.com/Bexy315/autocanvas/security/advisories/new) on this
repository, never as a public issue, discussion or pull request.

Say what is affected, how to reproduce it, and the version (shown at the bottom of the web UI's
sidebar). You get an answer as soon as possible; a fix is published together with an advisory.

AutoCanvas is pre-alpha and has no releases yet, so fixes go into `main` only. How AutoCanvas
protects sessions, secrets and runners is described in [Security](docs/technical/security.md).
